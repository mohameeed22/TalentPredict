1. Vue d’Ensemble du Système
1.1 Objectif du Système
L’application vise à évaluer les compétences techniques et comportementales des
collaborateurs en combinant : - Tests psychométriques PCM (Process
Communication Model) - Analyse automatique des projets GitHub - Comparaison CV
vs compétences réelles détectées - Recommandations de formation personnalisées
via IA - Workflow de validation et suivi
1.2 Modules Fonctionnels Principaux
Module Responsabilité Complexité
Authentication Gestion JWT, rôles, permissions Moyenne
Evaluation PCM Passation tests, calcul scores Moyenne
GitHub Analyzer API GitHub, parsing projets, extraction skills Élevée
AI Recommendation Intégration OpenAI, génération
recommandations
Élevée
Formation CRUD formations, inscriptions, suivi Faible

1.3 Stack Technique de Base
Frontend: - Framework: Angular (dernière version LTS) - UI Library: Angular
Material - Charts: Chart.js / D3.js - State Management: NgRx (optionnel)
Backend: - Langage: Java 17+ - Framework: Spring Boot 3.x - ORM: Spring Data JPA
/ Hibernate - Sécurité: Spring Security + JWT
Base de Données: - SGBD: PostgreSQL 15+ - Schéma: par module (tables préfixées)
Workflow: - Engine: Camunda 7.x (embedded ou standalone) - Notation: BPMN 2.0
Infrastructure: - Conteneurisation: Docker - Orchestration: Kubernetes (AWS EKS)
- CI/CD: GitLab CI / GitHub Actions - Registry: AWS ECR
APIs Externes: - OpenAI API (GPT-4 ou GPT-4-turbo) - GitHub REST API v3 - Jira
Cloud REST API v3

probables - Agilité maximale avec modulaire
