1. AUTHENTICATION MODULE
================================================================================

------------------------------------------------------------------------------
1.1 REGISTER NEW USER
------------------------------------------------------------------------------
Method: POST
URL: http://localhost:8081/api/auth/register
Headers:
  Content-Type: application/json
Body (JSON):
  {
    "email": "john.doe@example.com",
    "password": "SecurePass123!",
    "firstName": "John",
    "lastName": "Doe"
  }
Params: None
Expected Result (201 Created):
  {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "userId": 1,
    "email": "john.doe@example.com",
    "firstName": "John",
    "lastName": "Doe",
    "role": "USER"
  }
Notes: Save the token for subsequent requests

------------------------------------------------------------------------------
1.2 LOGIN
------------------------------------------------------------------------------
Method: POST
URL: http://localhost:8081/api/auth/login
Headers:
  Content-Type: application/json

  {
    "email": "john.doe@example.com",

================================================================================
COMMON HTTP STATUS CODES
================================================================================

200 OK - Request successful, response contains data
201 Created - Resource successfully created
204 No Content - Request successful, no response body
400 Bad Request - Invalid request data or validation error
401 Unauthorized - Missing or invalid authentication token
403 Forbidden - User lacks permission for requested resource
404 Not Found - Resource does not exist
409 Conflict - Resource already exists or constraint violation
500 Internal Server Error - Server error occurred

  GET http://localhost:8081/api/dashboard/users/{userId}

  GET http://localhost:8081/api/recommendations/users/{userId}

  PUT requests to update skills, formations, profile

  DELETE requests to remove test data


================================================================================
AUTHENTICATION NOTES
================================================================================

- All endpoints except /auth/register and /auth/login require JWT token
- Include token in Authorization header: "Authorization: Bearer {token}"
- Token expires after configured time (check application.properties)
- Refresh token by logging in again
- Users can only access/modify their own resources unless they are ADMIN
- Role-based access control enforced on sensitive operations
